## 🚀 Featured Projects

### ⚽ Graph-RAG FPL Assistant
**Graph Retrieval · Machine Learning · MLOps**

An AI-powered Fantasy Premier League assistant combining a Neo4j knowledge graph, semantic retrieval, and XGBoost predictions.

- 180K+ graph relationships.
- 166K player-match training records.
- 13.5% improvement in top-20 player selection quality over the best baseline.
- Automated data ingestion, prediction generation, and guarded retraining.
- Docker deployment, Azure hosting, GitHub Actions CI/CD, and 200+ automated tests.

🔗 [Live Demo](https://pitchme.polandcentral.cloudapp.azure.com/) · [Source Code](https://github.com/youssef20031/ACL_M3)

### 🩻 X-CV: X-Ray Computer Vision Pipeline
**Deep Learning · Object Detection · Computer Vision**

An end-to-end application integrating X-ray classification, fracture detection, localization, and AI-generated reports.

- Integrated MobileNetV2, DenseNet121, RT-DETR, YOLO, and Faster R-CNN.
- Identified and addressed near-duplicate data leakage.
- Rebuilt dataset splits using perceptual hashing and patient-level grouping.
- Achieved ROC-AUC scores of 0.93 and 0.98 on held-out test sets.

### 🌐 Code-Switched Arabic QA RAG System
**NLP · Retrieval-Augmented Generation · Vector Search**

A question-answering system built for complex transcripts mixing Egyptian Arabic, Modern Standard Arabic, and English.

- Developed text normalization for dialect-heavy, multilingual content.
- Integrated ChromaDB for contextual retrieval.
- Built a pipeline for answering questions about unstructured conversations.
